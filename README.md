# minipc-power

Small power board for MCU-based emulator builds: USB-C PD (9 V, 5 V fallback) or a 1S2P 18650 pack in, charges the
pack when plugged in, and supplies switched 5 V and 12 V outputs on solder pads.

- `docs/requirements.md` - requirements and architecture (start here)
- `docs/review-2026-10-24.md` - design review: what was fixed, what is open, owner decisions, bench checks
- `docs/skill-gaps.md` - problems found in the kicad-skills plugin while designing this board
